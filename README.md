# QuickNotes

QuickNotes is a small note-taking web app built with HTML, CSS and JavaScript. You can add short notes, sort them into categories, search through them and delete them. Your notes are saved in the browser, so they are still there after you refresh the page.

## Features
- Add notes with a category (Personal, Work or Study)
- Validation: no empty notes, maximum 200 characters
- Delete individual notes
- Live search that ignores upper/lower case
- Note count message (none, one or many)
- Notes saved with localStorage
- Clear all button with confirmation
- Responsive layout for small screens

## How to run locally
1. Clone the repo: `git clone https://github.com/YOUR-USERNAME/quicknotes-app.git`
2. Open the `quicknotes-app` folder.
3. Double-click `index.html` to open it in your browser (or use Live Server in VS Code).
